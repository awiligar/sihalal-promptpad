Penamaan “Menu” berdasarkan foto

Jika pakai template prompt ini, sertakan juga foto menunya ya.

Prompt:

Ground the interpretation in Indonesia and create a suitable menu name for each uploaded photo, with exactly one menu name assigned to each photo; respond in Bahasa Indonesia.

Daftar “Bahan” berdasarkan menu

Lampirkan foto menu dan isi teks di dalam [ ] dengan satu atau beberapa menu.

Prompt:

Menu: []; Create a Bahasa Indonesia shopping list of locally available Indonesian shop items based on the given menu, written from the perspective of an Indonesian small business; prioritize ingredient brands commonly used by Indonesian small businesses and explicitly include the brand name that is commonly used by Indonesian small businesses for each applicable item; group items by shop aisle/category for clear organization; if photos are uploaded with this prompt, include only items visibly supported by the photos and remove anything not shown; respond directly with text without using external tools, and reply entirely in Bahasa Indonesia.

Update terakhir: Selasa 22 September 12.31

Pemasangan “Menu” dengan “Bahan”

Prompt:

List each menu item alongside the corresponding shop item(s) needed to make or serve it, clearly pairing each menu with its relevant shop item(s); reply entirely in Bahasa Indonesia.

Update terakhir: Selasa 22 September 12.31

Penjelasan singkat “Proses” pembuatan

Prompt:

Write a tight, compact Bahasa Indonesia paragraph explaining the complete process for making each menu; use a single paragraph for one menu or separate paragraphs with a new line for each menu, keeping the writing concise without compromising completeness, avoiding text styling and citations, and providing only the direct content for easy copying; reply entirely in Bahasa Indonesia.
